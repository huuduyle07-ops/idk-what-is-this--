# Frozen semantic minima audit

All work is static source/schema analysis. No owner import, live observation, capability, controller, process launch, Docker invocation, or network request is needed for these facts.

Every field in each closed schema record remains present. Materialization and compilation each return the complete `workspace_state` record (`message_schema.json:840`, `:862`). Mutation poststate has its own single-use prebound observation challenge/sequence and is never a current readiness response. The owner requires a new `OBSERVE_*` challenge before readiness or handoff (`message_schema.json:1023`).

The smallest truthful quiescent prepared snapshot includes the controller, at least its main task, all seven namespace fields and a cgroup identity. A zero-process or zero-task controller snapshot is invalid. Compilation completes only after reaping and both EOFs (`controller contract.json:727`); the prepared-artifact predicate excludes a running compiler or target JVM. Reviewed candidate A makes the controller PID1, with parent PID0 and main TID1. The semantic contracts themselves are architecture independent. Controller UID/GID are 65534. Both mounts and their root metadata remain required, ordered `/tmp`, `/work`, with exact frozen options, root identities, namespace/generation, filesystem kind `tmpfs` and no subordinate mounts.

Every potential or open writer must be accounted by its exact original owner relation (`message_schema.json:1025`). A controller running as 65534 can potentially write both 01777 roots. The representative one-writer/two-root-handle profile captures that fact; the frozen schema does not separately settle the minimum descriptor/potential-access record representation. A writer-free record is therefore useful only as a strictly smaller mathematical relaxation, never as a feasible truthful witness.

The manifests are fixed. Empty has no entries. Materialized contains the 239-byte exact source and classes directory. Prepared adds the sole class file. UTF-8 path order puts the source before the directory. Files have link count 1 and exact size/hash; directories retain null size/hash. Source SHA256 is `813a17fd33e9c3d5a9bdc5bb6f8158e97ad7b021c3a0d2915ef68e45b0f09302`. A class size of 1 is a conservative decimal-width relaxation and never truthful successful javac output. Actual class SHA256 and exact byte size are not frozen measurements.

Compiler identity retains the fixed executable/hash, full eight-argument list, cwd, eight-variable environment, immutable image identity, seven namespaces and cgroup. Capture/reap retains exit 0, `timed_out=false`, `reaped=true`, `group_terminated=true`, `selectors_closed=true`, actual child/group/deadline relations, and both complete streams. Each stream has observed bytes 0, limit 2048, exact empty SHA256 `e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`, EOF/closed true and overflow false. The semantic message contains no raw captured bytes.

Challenges and all hashes have an exact 64-character encoding. Full container IDs are required, and reviewed candidate A explicitly uses full 64 lowercase hex. Candidate A also requires independent 32-byte hex workspace/controller generation tokens (`selection.json:generations`). The controller/workspace semantic contracts type those generation fields as `id` without a frozen textual width; that distinction must remain visible when transport is unselected.

Workspace capability, controller, request/operation, admission, attempt/receipt, owner/borrower, mount/root/namespace/cgroup, process/task/start/group, descriptor and deadline IDs identify exact authenticated original relations. No frozen format states that all are SHA256 or 64-hex. Their exact attainable textual minima are unresolved. The universal inequality that a nonempty canonical JSON string has at least three bytes is a safe lower-bound relaxation; substituting a one-character invented ID does not construct an execution or a valid semantic witness. Process incarnation still requires the original start/namespace/cgroup/container/channel relation, even if its eventual reference encoding is short.

The prior sizing data gives candidate A relaxed response payloads 2911, 4465 and 3064 bytes for materialize, compile and fresh prepared observation without writer records: 7376 bytes for the first two, and 10440 for all three. Frames add 4 bytes each. Thus three responses alone have a relaxed payload excess of 2248 over8192. This conditional arithmetic cannot determine attempt-cap membership. Two responses alone are below8192, even in the prior one-writer profile (8096 framed). Unknown real identifier widths can raise either count but cannot establish a truthful feasible witness from the prior labels.

`OBSERVE_PREPARED_ARTIFACTS` has an existing preparation receipt ID in its request. Frozen text requires fresh integrity for readiness/handoff; it does not uniquely require that exact tag before issuing its own prerequisite receipt. Likewise, mandatory cleanup persists after retained preparation success. The separate lifecycle/attempt boundary audit must decide which later obligations lie within the cumulative preparation interval; field minima cannot silently decide that scope.
