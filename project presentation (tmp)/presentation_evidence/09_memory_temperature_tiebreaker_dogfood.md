# 09 Memory Temperature Tie-breaker Dogfood

This is an evidence-only dogfood of the Phase 13.9 Memory Temperature
tie-breaker. When enabled, the tie-breaker only reorders lesson
candidates *within* a near-equal relevance group (hot/warm memories
rise, cold ones fall); the relevance score and the overall ranking are
preserved. It is off by default (an opt-in editable toggle).

- Live retrieval is unchanged.
- CONTROL prompt is unchanged.
- `MEMORY_TEMPERATURE_RETRIEVAL_ENABLED` is off by default (an opt-in editable toggle; this pack never enables it).
- Cold memories are never hard-filtered (they only lose priority inside a near-equal group).
- Frozen / audit-only / blocked memories are excluded from CONTROL and are never revived or surfaced.

The representative preview below was generated by `core.memory_temperature_retrieval_dogfood` from a deterministic, built-in sample candidate set (no DB or `lesson_store` query).
