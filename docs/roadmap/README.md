# Phase roadmap

[Documentation home](../README.md)

Phase reports, attempts and their evidence are grouped under `phases/<PHASE_NAME>/`.
Folder names mirror report filename stems; retries and lifecycle retries stay with their parent phase.
For new phase work, place the report and its JSON/text companions together in that phase folder.

## Historical paths

The [relocation map](organization/relocations.json) records each former path, current path and before/after SHA-256.
Historical JSON values, source citations, commands, registry metadata and captured logs describe their original context and are not rewritten.
Moved Markdown changes are limited to relative links so navigation keeps working.
